# env_mgr

Manage your development environments quickly and consistently.

## Note

This project is currently developed in Go. If you want to use it, please install Go first: [Install Go](https://go.dev/doc/install).

## Supported Languages

- [Java](https://www.java.com/)
- [Go](https://go.dev/)
- [Rust](https://www.rust-lang.org/)
- [Node.js](https://nodejs.org/)

## Roadmap

We plan to support more languages in future releases.
